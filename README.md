# GWAS-LD-FM-GS

This repository contains the analysis scripts used in the study:

**GWAS + LD-based SNP prioritization, Bayesian fine-mapping, and genomic selection**

The repository provides the code used to connect GWAS-based SNP prioritization and SuSiE-RSS fine-mapping with subsequent genomic prediction.

The repository is intended for reproducibility of the analyses reported in the manuscript rather than as a standalone software package.

---

## Analysis workflow

The overall analysis workflow is:

```text
GWAS summary statistics
          |
          v
     LD clumping
          |
          v
 GWAS + LD prioritization
          |
          v
   Representative SNPs
          |
          v
      SuSiE-RSS
          |
          v
   Posterior inclusion
   probabilities (PIP)
          |
          v
      PIP ranking
          |
          v
     SNP subsets
          |
          v
   Genomic prediction
       /       \
      /         \
   GBLUP      BayesC
```

The five scripts in this repository correspond to the main computational steps of this workflow.

## Repository contents

### 1. `select_lead_snps.py`

Selects representative SNPs from LD clumps based on GWAS significance.

For each LD group generated by PLINK, the SNP with the smallest GWAS P-value is selected as the representative SNP.

Conceptually:

```text
LD group
    |
    +-- SNP1   P = 1.2e-5
    +-- SNP2   P = 3.4e-8   <--- selected
    +-- SNP3   P = 7.1e-6
```

Example:

```bash
python select_lead_snps.py \
    --gwas trait1_gwas.txt \
    --clumped trait1.clumped \
    --output trait1_lead_snps.txt
```

The LD clumping itself is performed using PLINK. This script performs the subsequent GWAS-based prioritization within each LD group.

---

### 2. `run_susie_rss.R`

Performs Bayesian fine-mapping using SuSiE-RSS through the `susieR` R package.

The script takes GWAS summary statistics and an LD correlation matrix as input and produces SNP-level posterior inclusion probabilities (PIPs) and credible sets.

Example:

```bash
Rscript run_susie_rss.R \
    --gwas trait1_gwas.txt \
    --ld trait1_LD.txt \
    --output trait1
```

The default maximum number of effects is:

```text
L = 10
```

The default credible-set coverage is:

```text
0.95
```

Main outputs include:

```text
trait1_PIP.txt
trait1_credible_sets.txt
trait1_summary.txt
```

The SuSiE-RSS implementation itself is provided by the `susieR` package and is not reimplemented in this repository.

---

### 3. `summarize_susie_results.py`

Combines and ranks SNP-level PIP results.

The script can be used when SuSiE-RSS results are generated separately, for example across chromosomes or multiple analyses.

Example:

```bash
python summarize_susie_results.py \
    --input chr1_PIP.txt chr2_PIP.txt chr3_PIP.txt \
    --output combined_PIP.txt
```

The resulting SNP list is ranked according to decreasing PIP.

---

### 4. `run_gblup.R`

Performs genomic prediction using GBLUP.

The script reads the PIP results generated by the fine-mapping step and selects the top-N SNPs according to PIP.

For example:

```bash
Rscript run_gblup.R \
    --genotype genotype.txt \
    --phenotype trait1.txt \
    --pip trait1_PIP.txt \
    --top_n 5000 \
    --folds 10 \
    --seed 12345 \
    --output trait1_GBLUP_top5000
```

The same PIP-ranked SNP subsets can therefore be evaluated using different genomic prediction models.

GBLUP is implemented using the `rrBLUP` R package.

---

### 5. `run_bayesc.R`

Performs genomic prediction using BayesC.

The script uses the same PIP-ranked SNP subsets as the GBLUP analysis to maintain consistency when comparing genomic prediction models.

Example:

```bash
Rscript run_bayesc.R \
    --genotype genotype.txt \
    --phenotype trait1.txt \
    --pip trait1_PIP.txt \
    --top_n 5000 \
    --folds 10 \
    --seed 12345 \
    --output trait1_BayesC_top5000
```

BayesC is implemented using the `BGLR` R package.

---

## Relationship between fine-mapping and genomic prediction

The central purpose of the analysis is to evaluate whether fine-mapping-based SNP prioritization can improve or maintain genomic prediction performance using a reduced set of SNPs.

The PIP ranking generated by SuSiE-RSS is therefore used to construct SNP subsets of different sizes.

For example:

```text
SuSiE-RSS PIP ranking
        |
        +---- Top 100 SNPs
        |
        +---- Top 500 SNPs
        |
        +---- Top 1,000 SNPs
        |
        +---- Top 5,000 SNPs
        |
        +---- Top 10,000 SNPs
```

The same SNP subset is supplied to GBLUP and BayesC when comparing the two genomic prediction models.

---

## Cross-validation

The genomic prediction scripts use 10-fold cross-validation by default.

The following metrics are reported:

* Pearson correlation coefficient (PCC)
* Mean squared error (MSE)
* Root mean squared error (RMSE)

Both fold-level results and pooled out-of-fold predictions are saved.

For each analysis, the main output files are:

```text
*_fold_results.txt
*_summary.txt
*_OOF_predictions.txt
```

## Software requirements

### Python

The Python scripts require:

* Python >= 3.8
* pandas

Install pandas using:

```bash
pip install pandas
```

### R

The R scripts require:

* R >= 4.0
* `susieR`
* `rrBLUP`
* `BGLR`

The packages can be installed using:

```r
install.packages("susieR")
install.packages("rrBLUP")
install.packages("BGLR")
```

LD clumping is performed using PLINK.

## Reproducibility and versioning

The repository is versioned using Git tags/releases.

The versioned release associated with the manuscript corresponds to the code used for the analyses reported in the present study.

For reproducibility, users should use the specific release/tag associated with the manuscript rather than the latest version of the repository.

The manuscript is linked to this fixed release rather than to the continuously updated main branch.

The repository may be updated after publication for documentation, maintenance, or clarification. Such updates do not replace the versioned release associated with the published study.

## Data availability

The raw genotype and phenotype data used in the study are not included in this repository because of data-use and/or availability restrictions.

The scripts are provided to document the computational procedures used in the manuscript.

Users wishing to reproduce the analyses with their own data should prepare equivalent GWAS summary statistics, LD matrices, genotype matrices, and phenotype files according to the input formats described above.
